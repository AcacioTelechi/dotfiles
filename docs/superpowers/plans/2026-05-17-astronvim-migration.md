# AstroNvim Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the hand-rolled Neovim config with the AstroNvim v6 template, re-applying the user's keymaps, options, colorscheme, and one personal plugin as AstroNvim overrides.

**Architecture:** AstroNvim v6 distribution owns `nvim/.config/nvim/` (a stow package symlinked to `~/.config/nvim`). User preferences live in the template's override files: `lua/plugins/astrocore.lua` (options + mappings), `lua/plugins/astroui.lua` (colorscheme), `lua/community.lua` (language + colorscheme packs), `lua/polish.lua` (undodir), `lua/plugins/user.lua` (vim-tmux-navigator). Work happens on branch `astronvim-migration`, validated headless, then merged to `main`.

**Tech Stack:** Neovim, AstroNvim v6, AstroCommunity, lazy.nvim, git, GNU stow.

---

## File Structure

- `nvim/.config/nvim/` — entire directory replaced with AstroNvim v6 template.
- Old `nvim/.config/nvim/init.lua` — deleted (template provides its own).
- Old `nvim/.config/nvim/lazy-lock.json` — deleted (regenerated by AstroNvim).
- Customization files edited: `lua/community.lua`, `lua/plugins/astroui.lua`, `lua/plugins/astrocore.lua`, `lua/polish.lua`, `lua/plugins/user.lua`.
- Neovim runtime dirs (`~/.local/share/nvim`, `~/.local/state/nvim`, `~/.cache/nvim`) — moved aside to `.bak` for a clean distro slate (reversible).

Note: several template files begin with `if true then return ... end -- WARN: REMOVE THIS LINE TO ACTIVATE THIS FILE`. Activating a file means deleting exactly that first line. `lua/plugins/astrocore.lua` ships active (no guard).

```lua

        ["<A-j>"] = { ":m .+1<CR>==", desc = "Move line down" },
        ["<A-k>"] = { ":m .-2<CR>==", desc = "Move line up" },
        ["<A-h>"] = { "<<", desc = "Indent left" },
        ["<A-l>"] = { ">>", desc = "Indent right" },
        ["<S-A-j>"] = { ":t.<CR>", desc = "Duplicate line down" },
        ["<S-A-k>"] = { ":t.-1<CR>", desc = "Duplicate line up" },
        ["<F12>"] = { function() vim.lsp.buf.definition() end, desc = "Goto definition" },
        ["<S-F12>"] = { function() vim.lsp.buf.references() end, desc = "Find references" },
      },
      v = {
        ["<A-j>"] = { ":m '>+1<CR>gv=gv", desc = "Move selection down" },
        ["<A-k>"] = { ":m '<-2<CR>gv=gv", desc = "Move selection up" },
        ["<A-h>"] = { "<gv", desc = "Indent left and reselect" },
        ["<A-l>"] = { ">gv", desc = "Indent right and reselect" },
        ["<S-A-j>"] = { ":t '><CR>gv=gv", desc = "Duplicate selection down" },
        ["<S-A-k>"] = { ":t '<-1<CR>gv=gv", desc = "Duplicate selection up" },
        ["<"] = { "<gv", desc = "Indent left and reselect" },
```
